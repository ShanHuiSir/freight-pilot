    明确的业务假设

    • 总成本 = max(Min_Cost, 货物重量 × Rate)。最低收费是费用下限，不额外叠加。
    • 重量区间上下限均包含，订单重量最多两位小数。Decimal 精确核算后，展示金额四舍五入到两位。
    • 时效按 TPT_Day_Count ≤ 最大运输天数筛选。保留原表中的 0 天值，使用前需业务确认。
    • DTD 与 DTP 属于不同服务代码，可通过服务筛选保持同口径比较；如选择全部，允许跨服务比较。
    • 原表没有注明币种、重量单位、报价有效期、税费、体积重、燃油附加费和容量。不推断这些信息。
    • 最低成本范围是本次有效匹配报价。单笔订单整体交由一个方案，批量逐单独立计算。
    • Pareto 标记仅表示同次匹配中未被费用更低且时效更快的方案支配，不替代最低成本推荐。
    • 模拟订单用于演示，原始比赛报价未获得外部商业真实性验证。DeepSeek 用于需求提取和解释，价格由规则引擎计算。
