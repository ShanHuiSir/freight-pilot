# 使用与部署

## 可执行产品

Release 提供 macOS Apple Silicon 程序和 Windows x64 程序。可执行程序包含 Python 运行时、界面、内置比赛报价及 Excel 处理依赖。启动后自动打开默认浏览器；关闭控制台结束服务。应用只监听 `127.0.0.1`，不需要公网部署。

macOS Apple Silicon 使用交付整包中的 `启动运筹.command`。单独下载程序时，先在终端执行 `chmod +x FreightPilot-macOS-arm64`，再运行 `./FreightPilot-macOS-arm64`。终端模式是实际可执行产品，不是安装包或后台云服务。若首次启动被系统要求确认，在系统设置按正常方式允许此下载程序；不需要关闭系统保护。该程序未做 Apple 商业证书签名/公证。Windows 下载 `FreightPilot-Windows-x64.exe` 后双击。

默认端口 8899。端口被占用时添加 `--port 8900`。`--no-browser` 只启动服务，适合自动验证。源代码启动方式见 README；需要 Python 3.10+，安装 `requirements.txt`。

## 模型设置

1. 将 `.env.example` 复制成 `.env`，与 `app.py` 或可执行文件放在同一目录。
2. 设置 `DEEPSEEK_API_KEY=你的密钥`；`DEEPSEEK_MODEL=deepseek-chat`。
3. 重启。左下角显示模型配置状态；实际联网能力以解析/简报的成功响应为准，配置状态不代表网络验证。

密钥仅在本地服务端读取，不传到浏览器。未配置模型仍可录入订单、固定格式解析、单笔及批量核算、全部导出。模型接口失败会显示原因，不替换成伪造的 AI 响应。

## 单笔订单

必填：重量（>0，最多两位小数）、起运港代码、目的港代码。可选：最大运输天数（非负整数）、服务等级 DTD/DTP、运输方式 AIR/GROUND。全部服务意味着允许不同服务代码参与同次比较，采购应按需求主动限制。

自然语言请使用数据中的代码，示例：`800 报价单位，从 PORT06 到 PORT09，3 天内到达，DTD AIR`。DeepSeek 提取后必须人工核对字段，再执行核算。不得把任意城市名称自动映射成附件港口。

推荐卡展示总费用、时效、公式与原始报价行号。所有匹配方案默认保留超时记录，可以勾选仅看满足要求。无匹配或无满足时效方案时，明确无推荐。

## 输入文件

报价支持 CSV/XLSX（第一工作表、值表、最大 8 MB、解压后不超过 32 MB、最多 20,000 行）。表头需要：

`Carrier,Orig_Port,Dest_Port,Min_Weight_Quant,Max_Weight_Quant,Service_Level,Min_Cost,Rate,Mode_DSC,TPT_Day_Count,Carrier_Type`

CSV 支持 UTF-8（含 BOM）与 GB18030。去除字段首尾空格，港口、服务与运输方式转大写。完全重复报价去重；必填缺失、非法数值、倒置区间等行被隔离。无有效报价的文件拒绝导入，保留原来的报价版本。

批量订单必需 `id,weight,origin,destination`，可选 `max_days,service,mode`；支持对应中文表头，见模拟模板。最大 1,000 笔。编号必须唯一，重复编号的后续行标无效。金额合计只包括成功推荐订单，每笔订单独立最优。

## 导出

单笔 ZIP：`比价结果.xlsx`、`比价明细.csv`、`运输方案简报.html`、`运输方案简报.md`、`运行快照.json`。

批量 ZIP：推荐清单 CSV、结果 XLSX、汇总简报、逐单简报、运行快照。AI 简报如已生成也在快照中，作为辅助文本保留，不替代核算。HTML 可在浏览器预览并使用浏览器打印功能另存 PDF；应用未单独实现 PDF 生成器。

结果默认保存在用户主目录 `.freight-agent/`。通过 `FREIGHT_DATA_DIR` 可指定本地结果目录。报价上传版本保留在本次服务内存中，重启需重新导入；已导出的快照包含使用的文件哈希、报价证据与核算明细，可复核。

## 验证与构建

运行 `python -m unittest discover -s tests -v`。安装桌面构建依赖后执行 `python scripts/build.py`，得到当前平台程序。执行 `python scripts/smoke_executable.py` 验证程序能启动、算出 67.84 并导出 XLSX。Windows exe 必须在 Windows 构建；仓库 CI 提供自动构建及验收，不通过修改 macOS 文件扩展名冒充 exe。

GitHub Release 的附件是交付整包；提交整包内包含视频、字幕、解说词、文档、示例输入、示例运行成果、源码及可执行程序，文件校验表标明 SHA-256。
