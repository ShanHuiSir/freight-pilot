# 数据口径与能力边界

## 来源与假设

使用附件原始 FreightRates.csv，不修改原文件。原始1,540行、9个承运商、10条路线，目的港都是 PORT09；完全重复3行去重后1,537行。`AIR   ` 规范化为 `AIR`；区间包含上下端点。

赛题未提供详细计费合同，本项目采用常见最低收费下限规则：`max(Min_Cost, weight × Rate)`。此为实现假设，实际签约规则须业务确认。原表未给重量单位与币种，统一展示“报价单位 / 货币单位”，不推断公斤/人民币。若输入自然语言含公斤，也只提取数值，不做物理单位换算，用户必须确认其与报价口径一致。

原表 TPT_Day_Count 含0，保留原值不擅自修正；0天是否业务合理须确认。不同承运商、服务、时效、区间的记录独立保留，不把同一承运商不同方案合成一条。完全重复只保留第一次出现行号。

Min_Cost 和 Rate 使用原始小数精度，以 Decimal 算出未舍入成本后推荐；显示金额 ROUND_HALF_UP 到2位。同费用依次按时效、承运商代码、原表行号确定稳定推荐。总额为逐单原始成本相加后展示四舍五入，小数可能与逐行展示金额求和差0.01，须据此对账。

## 已验证

单笔和批量导入、报价去重与非法行隔离、路线和重量匹配、时效核对、最低费用推荐、无解标记、计费证据、Pareto 标记、CSV/XLSX/HTML/Markdown/JSON 导出。真实 DeepSeek 需求解析与简报调用，元数据见实测快照；模型不决定费用。

演示为自动化驱动的真实浏览器操作。画面连续采集，不以静态产品截图制作伪操作；字幕、章节标题和鼠标可视化为辅助图层。解说为本机中文神经语音合成。业务订单为模拟数据，报价来自比赛样例。视频中的67.84、230.72、341.79均为实际运行结果。

## 不支持或未验证

- 体积重、装卸/税费/燃油附加费、币种换算和单位换算。
- 承运商容量、仓网、多段路线、拆单/拼单、跨订单联合优化。
- 商业报价真实性、合同效力、实时运价和运输实际履约。
- 多用户生产服务、认证授权和公网部署；当前为本机个人工作台。
- 任何平台的自动代提交、获奖或时效加分承诺。

“最低成本”严格指有效报价内、同次订单约束下的最小成本；不代表全市场最优。相对最快方案的费用差是模拟比较基准，不是已有采购预算、实际支出或实现的节省。AI 文字须核对，报价表与规则计算是费用依据。
