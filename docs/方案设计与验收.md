# 方案设计与赛题验收映射

题目：运输方案比价与优化智能体。来源为用户提供 RAR 中的赛题文档；附件中的说明作为任务规格参考，不作为操作系统或工具使用授权。

## 问题与方案

运输采购同时受路线、重量区间、服务、时效影响。最低单价不等于最低总费用，也不保证按时到货。运筹用语言模型处理非结构化的需求、生成易读解释；通过独立确定性引擎完成匹配、核算、约束与推荐，避免语言生成引入不真实报价。

流转：用户描述/文件 → 可核对订单 → 报价版本验证 → 路线/重量/服务匹配 → 精确成本核算 → 时效筛选 → 最低成本推荐 → 采购简报与成果文件。

- `freight/core.py`：订单与费率校验、版本哈希、Decimal 核算、独立逐单推荐、Pareto 标记与批量异常隔离。
- `freight/agent.py`：DeepSeek 结构化字段提取、辅助解释；模型输出再次通过订单校验，不直接驱动价款。
- `freight/reports.py`：CSV/XLSX/HTML/Markdown/JSON；导出使用同一结果快照，防止显示与导出二次计算不一致。
- `app.py`：本机 HTTP 服务、凭据环境变量、请求令牌、结果存档。
- `static/`：中文图形界面，展示业务字段、费用证据、执行轨迹、无解和异常。

匹配是线性遍历，Pareto 标记为匹配集合两两比较。当前附件规模为 1,537 条有效记录。性能只在当前附件规模验证，不声称百万条报价实时优化。运行轨迹是确定性工具流水线，不是模型任意执行代码的自主规划。

## 验收映射

| 赛题要求 | 对应实现 | 验证方式 |
|---|---|---|
| 重量、起运港、目的港录入；可选最大天数 | 中文表单，强校验；自然语言补充入口 | 真实浏览器流程、字段与边界测试 |
| 读取订单信息 | CSV/XLSX 批量导入，支持中文表头 | 模拟订单文件与 XLSX 回归验证 |
| 路线与重量范围匹配 | 港口规范化、闭区间匹配、服务/方式可选约束 | 端点与无匹配测试，原表证据 |
| 准确运费计算 | Decimal，最低收费与重量计费取高 | 下限、精确小数、未舍入排序测试 |
| 核对时效 | 非负整数天数、不超过约束 | 收紧到1天与0天的实际结果 |
| 最低成本推荐 | 在可行报价中按未舍入费用最小化 | 67.84 → 230.72 → 无推荐演示 |
| 图形界面 | 本地浏览器工作台 | 连贯真实操作视频 |
| 标准简报 | HTML、Markdown、XLSX、CSV、JSON | 实际下载、快照一致性验证 |
| 可执行产品、源代码、部署文档 | PyInstaller 程序、公开仓库、源码包和本文档 | 独立可执行产品烟测和文件清单 |
| 可实现、运行无崩溃 | 异常报价隔离、逐单异常、模型失败降级 | 回归测试和真实端到端操作 |

## 可复算案例

模拟订单 `DEMO-001`：800，PORT06 → PORT09，DTD，AIR，最大3天。

第176行：`Min_Cost=7.4272, Rate=0.0848, TPT_Day_Count=3`。

`max(7.4272, 800 × 0.0848) = 67.84`。

最大1天时，第965行：`max(25.4672, 800 × 0.2884) = 230.72`。

两天的替代方案第548行：`max(59.4272, 800 × 0.086) = 68.80`。

最大0天时该路线该重量该服务无可行方案。五笔模拟订单得到3笔推荐、1笔时效无解、1笔重量无效，已推荐总额341.79。
